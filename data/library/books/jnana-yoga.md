# Jnana Yoga

> *Intellectual inquiry as a path to the divine*

Vivekananda's case that the mind doesn't have to shut up to touch something transcendent, it just has to aim correctly. For someone who lives in code and text and structured thought, this was permission to seek truth through the tools already at hand.

Vivekananda brought [Vedanta](/knowledge/spirituality/vedanta) West in 1893, establishing the translation tradition that [Ram Dass](/knowledge/spirituality/ram-dass) continued. Kenneth continues it further, translating the same insights through Python and AI collaboration. The path of knowledge (jnana) says understanding itself is liberation.
