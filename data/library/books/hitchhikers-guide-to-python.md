# The Hitchhiker's Guide to Python

> *The one Kenneth wrote himself*

A guide to Python best practices, community wisdom, and the philosophy that documentation should be beautiful and humane. It started as python-guide.org, became an O'Reilly book, and was eventually sold for $14,000. The title is borrowed from [Douglas Adams](/library/books/the-hitchhikers-guide-to-the-galaxy), because absurdity and profundity have always been the same thing.

The Guide treated documentation as a design problem: how do you make a programming language's ecosystem navigable for someone who doesn't already know where everything is? The answer was the same as always, figure out what the person needs, put it where they'd look for it, write it in language they understand. [For Humans](/knowledge/philosophy/for-humans), applied to knowledge.
