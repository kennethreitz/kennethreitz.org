# Monospace

> *Every character gets the same small room, and code is happier for it.*

---

## Fixed Width

In a monospaced (fixed-width) typeface every character occupies the same horizontal space: **i** and **m** take the same width. This is not a historical style but a technical constraint, born with the typewriter, whose carriage advanced by the same amount for every keystroke. Monospace is outside the Vox-ATypI scheme entirely.

## From Typewriter to Terminal

The classic typewriter faces, including [Courier](/knowledge/typography/typefaces/courier)[^sn-courier] (IBM, 1955), were [slab serifs](/knowledge/typography/classification/slab-serif), since the slabs helped fill out narrow letters in a wide cell. Computer terminals inherited fixed width because a screen of text was a grid of character cells. Programmers kept it because alignment matters in code: columns line up, indentation is exact, and every character, including spaces, is visible as a unit.

## The Modern Coding Font

Recent monospaced faces are designed for long hours of reading code: clear distinction between **0** and **O**, **1**, **l**, and **I**; generous [X-Height](/knowledge/typography/anatomy/x-height); and sometimes programming [ligatures](/knowledge/typography/anatomy/ligature). Examples include [IBM Plex](/knowledge/typography/typefaces/ibm-plex) Mono, [SF Mono](/knowledge/typography/typefaces/sf-mono), [Iosevka](/knowledge/typography/typefaces/iosevka), [Operator Mono](/knowledge/typography/typefaces/operator-mono),[^sn-operator-mono] and the *duospaced* [iA Writer Duo](/knowledge/typography/typefaces/ia-writer-duo), which relaxes the constraint just enough to give **m** and **w** extra room. This vault's own writing view is set in IBM Plex Mono (see [Draft to Document Why I Made My Notes Look Like LaTeX Papers](/essays/2026-11-04-draft_to_document)), a choice in the tradition of writing apps that use monospace to keep the writer focused on the words.
