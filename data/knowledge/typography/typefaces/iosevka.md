# Iosevka

> *A coding font compiled rather than drawn, and built to your order.*

---

## The Face

Iosevka is an open-source [Monospace](/knowledge/typography/classification/monospace)[^sn-monospace] family created by the designer and programmer Belleve Invis, first released in 2015. It is narrow by design, fitting more columns of code on screen, with a slender, slightly condensed look.

## Built From Code

Iosevka is generated by a build system rather than drawn glyph by glyph, and its source exposes hundreds of variant choices: the shape of **0**, **i**, **l**, **g**, and many symbols, slab or sans forms, spacing modes, and programming [ligatures](/knowledge/typography/anatomy/ligature). Users can compile a custom build to their own taste, which makes it a practical cousin of [Donald Knuth](/knowledge/typography/type-designers/donald-knuth)'s parametric [Computer Modern](/knowledge/typography/typefaces/computer-modern) and of [Variable Fonts](/knowledge/typography/history/variable-fonts).

## In Practice

Iosevka is popular in terminals and editors where screen width is precious. Its condensed proportions make it less suited to long prose than wider coding faces like [IBM Plex](/knowledge/typography/typefaces/ibm-plex) Mono or [SF Mono](/knowledge/typography/typefaces/sf-mono).
