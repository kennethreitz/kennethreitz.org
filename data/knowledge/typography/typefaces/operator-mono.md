# Operator Mono

> *A coding font with an italic that looks handwritten.*

---

## The Face

Operator Mono is the [Monospace](/knowledge/typography/classification/monospace)[^sn-monospace] companion of Hoefler & Co.'s Operator family, designed by Andy Clymer and released in 2016 (see [Jonathan Hoefler](/knowledge/typography/type-designers/jonathan-hoefler)). It was one of the first commercial coding fonts sold at a premium price to programmers.

## The Italic

Its signature is a cursive, script-like italic, unusual in a fixed-width face. Programmers use it with editor themes that render comments, keywords, or attributes in italic, so the code gains a second, handwritten voice alongside the upright roman (compare the joined forms of [Script](/knowledge/typography/classification/script) faces).

## In This Vault

Kenneth reviewed it when it came out in [Test-Driving a $200 Coding Font Operator Mono](/essays/2016-01-test_driving_a_200_coding_font_operator_mono), weighing whether a coding font could be worth that price.
