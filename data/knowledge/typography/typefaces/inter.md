# Inter

> *A typeface for the user interface, given away to everyone who builds one.*

---

## The Face

Inter is an open-source sans serif designed by the Swedish designer Rasmus Andersson specifically for computer screens, first released in 2017 under the name Interface and soon renamed. It is a [Neo-Grotesque](/knowledge/typography/classification/neo-grotesque) in the lineage of [Helvetica](/knowledge/typography/typefaces/helvetica), adjusted for small text on displays.

## Character

Inter has a very tall [X-Height](/knowledge/typography/anatomy/x-height), slightly more open [apertures](/knowledge/typography/anatomy/aperture) than Helvetica,[^sn-helvetica] and careful spacing for UI sizes. It is a [variable font](/knowledge/typography/history/variable-fonts) with weight and optical size axes, and includes a deep set of [OpenType Features](/knowledge/typography/practice-and-principles/opentype-features): tabular [Figures](/knowledge/typography/practice-and-principles/figures), a slashed zero, case-sensitive punctuation, and alternate forms for disambiguating letters.

## Uses

Inter became one of the most widely used interface faces in software and on the web. Kenneth's own site paired it with Crimson Pro in a custom typography system (see kennethreitz.org and the collaboration recorded in [note-from-ai](/artificial-intelligence/personal/note-from-ai)), a classic sans and serif pairing (see [Pairing Typefaces](/knowledge/typography/practice-and-principles/pairing-typefaces)).
