# Python

> *Not the language itself -- what it means to him*

---

## Overview

Python is how Kenneth thinks. Not in the way that a carpenter thinks in wood or a painter thinks in color -- more fundamentally than that. Python's philosophy became his philosophy. Its aesthetic became his aesthetic. The language didn't just give him a career; it gave him a way of seeing the world that eventually became [For Humans](/knowledge/philosophy/for-humans).

This isn't a note about Python the programming language. There are plenty of those. This is about Python as a way of being.

---

## The Philosophy Match

The Zen of Python reads like Kenneth's personal creed. "Beautiful is better than ugly. Explicit is better than implicit. Simple is better than complex. Readability counts." These weren't principles he learned and adopted -- they were principles he already held that he found articulated in a language. The fit was immediate and total.

When he built requests, he wasn't just wrapping urllib3 in a nicer interface. He was expressing the conviction that if something is hard to use, the tool is wrong, not the user. That conviction came from design instinct, but Python gave it a home. The language's insistence on readability -- significant whitespace, clear syntax, one obvious way to do it -- aligned with a mind that had always prioritized clarity over cleverness.

---

## The Work

The Python Libraries tell the story. requests made HTTP human-readable -- sixteen million machines use it daily, and most of them don't think about it, which is exactly the point. pipenv brought the same sensibility to package management. simplemind does it for AI interaction. tablib for tabular data. certifi for SSL certificates. records for SQL. Each one follows the same pattern: find a place where developers are fighting the tool, remove the fight, make it feel natural.

pytheory went somewhere unexpected -- music theory as Python objects. Scales, chords, progressions expressed in code. And pytheory-opxy extended it to the Teenage Engineering OP-XY synthesizer. Kenneth was writing music in Python. The language had become expressive enough to hold not just his technical work but his creative work too.

The Hitchhiker's Guide to Python was the documentation equivalent -- making Python itself more accessible, the same "for Humans" instinct applied to the language's own learning curve.

---

## Design, Not Engineering

The thing people misunderstand about Kenneth's Python work is that it was never primarily technical. He says it plainly: "I don't actually consider myself to be a good programmer. I consider myself to be a good designer disguised as a programmer." The requests API wasn't an engineering achievement. It was a design achievement -- understanding what the human on the other end needed before they knew they needed it, and then removing everything else.

Python enabled this because Python already valued the same things. A language that enforces readability is a language that has already decided the human matters more than the machine. Kenneth just took that decision further than most.

---

## The Career

Python gave Kenneth everything professionally. The Career Timeline traces it: from early open source work through the "Python Overlord" role at Heroku, PSF Board membership, the #1 most followed Python developer on GitHub, keynotes, influence, impact. Libraries processing billions of requests daily. Infrastructure so foundational it's invisible.

Python also, indirectly, gave him the burnout, the mental health intersection, the complicated relationship with open source that eventually led to stepping back. The language was the canvas; the community was the context; and context, it turns out, matters as much as code. But that's a story for Open Source.

---

## Python Now

Kenneth's relationship with Python has matured from creation to selective practice. simplemind remains the current Python expression of AI for Humans, while pytheory turns the language into an instrument. RetroVault marks a different kind of continuation: it is written in Swift rather than Python, but its native Mac interface carries the same readability, sensible-defaults, and human-first design instincts into a new medium. The older libraries live on, maintained by others, doing their work. The language is no longer the boundary of the practice, but the thinking style it shaped is permanent.
